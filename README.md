# RiboBridge

**RiboBridge couples RNA backbone generation to sequence design through a learned interaction topology.**

RiboBridge infers a probabilistic residue-pair state from generated RNA backbone geometry, recycles binary pair probabilities through a second structural pass, and transfers binary and typed pair signals to sequence decoding as soft attention biases.
